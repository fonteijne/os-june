# Button

Pill-shaped action in three variants. `primary` (accent fill, `on-accent` label) at most once per view for the one thing the section is for; `secondary` (hairline `line-strong`, inverts to `ink` on hover) for everything else; `inverse` only on a `surface-inverse` band. Consumer provides the label (verb first, sentence case) and `onClick` or `href`; `arrow` adds the signature → for forward navigation. Leave at least `space-6` above a button.
