Bring your local tools into Clovy

Register a tool you already own. Clovy can discover read-only capabilities without opening a second shell surface or sending your credentials to a service.

Rust owns the boundary

Clovy starts and stops the configured process, keeps secrets in the system keychain, and applies approval policy. The selected executable can still read the credentials you provide to it.
